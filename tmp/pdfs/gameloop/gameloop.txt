Visão Geral da Arquitetura do Jogo
O Operação Sentinela é dividido em módulos com responsabilidades bem definidas. O fluxo principal percorre entrada → atualização → renderização a 
cada quadro.
A Entrada recebe comandos do jogador. O Núcleo coordena a execução. O Mundo armazena o estado. As Entidades representam jogador, inimigos e 
objetos. A IA será integrada progressivamente ao longo do semestre.

O Que É um Game Loop?
O ciclo central que mantém o jogo funcionando enquanto a aplicação está ativa. Ele se repete continuamente, coordenando praticamente todos os 
sistemas do jogo.

O Problema da Dependência de FPS
O cenário
💻 Computador A — 30 FPS
O personagem recebe 30 atualizações por segundo
🖥️ Computador B — 120 FPS
O personagem recebe 120 atualizações por segundo
Com o código abaixo, o personagem se move 4× mais rápido no Computador B:
player.setX(player.getX() + 5);
Delta Time
Δt = tempo entre dois quadros 
consecutivos
O conceito
Delta time é o tempo transcorrido entre o quadro atual e o quadro anterior, normalmente expresso em segundos. Com ele, multiplicamos a 
velocidade pelo tempo real.
double speed = 50.0; 
player.setX(player.getX() + (speed * deltaTime));
Game Loop com AnimationTimer
O JavaFX oferece a classe AnimationTimer, cujo método handle(long now) é chamado repetidamente pelo framework, sincronizado com o ciclo de 
renderização da tela.
AnimationTimer gameLoop = new AnimationTimer() {
 @Override
 public void handle(long now) {
   processInput();
   update();
   render();
 }
};
gameLoop.start();
O que saber sobre o AnimationTimer
start() inicia o loop; stop() o interrompe
now representa o tempo atual em nanossegundos
O JavaFX executa o método dentro de seu fluxo de atualização visual
O AnimationTimer não deve conter toda a lógica — ele apenas 
coordena os componentes
O AnimationTimer é o ponto de entrada do loop, não o lugar 
para implementar regras do jogo.
Implementando o Delta Time
private long lastTime = 0;
private final AnimationTimer gameLoop =
 new AnimationTimer() {
   @Override
   public void handle(long now) {
     if (lastTime == 0) {
       lastTime = now;
       return;
     }
     double deltaTime =
       (now - lastTime) / 1_000_000_000.0;
     lastTime = now;
     processInput();
     update(deltaTime);
     render();
   }
 };
Passo a passo
1 Armazenar o tempo anterior
Guardar o valor de now do quadro anterior em lastTime
2 Calcular a diferença
Subtrair lastTime de now
3 Converter para segundos
Dividir por 1.000.000.000 (nanossegundos → segundos)
4 Atualizar e propagar
Enviar deltaTime para a lógica do jogo
O primeiro quadro precisa de tratamento especial — ainda não 
existe um tempo anterior válido.
Atualização, Renderização e Estados
Separação clara de papéis
private void update(double deltaTime) {
 player.update(deltaTime);
 world.update(deltaTime);
}
private void render() {
 renderer.clear();
 renderer.drawWorld(world);
 renderer.drawPlayer(player);
}
update() altera o estado do jogo
render() representa esse estado visualmente
A renderização não define regras
A lógica não depende do visual
